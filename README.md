# ICSSR Project to Empower women with Mushroom Cultivation

> A research testing website built for an ICSSR (Indian Council of Social Science Research) project focused on mushroom related data or research presentation.
> https://naman-uwoogh.github.io/Icssr-mushroom/

---

## About

This is a web-based testing interface developed as part of an ICSSR research project. The site serves as a frontend for presenting or interacting with project data related to mushroom research likely covering cultivation and agricultural data.

---


## Cmd

```bash
git clone https://github.com/naman-uwoogh/Icssr-mushroom.git
cd Icssr-mushroom
open index.html
```

No build step needed — open the HTML file directly in any browser.

---


## Research Context

This project was developed under the ICSSR (Indian Council of Social Science Research) framework. The mushroom focus may relate to agricultural economics, rural livelihood studies, or biodiversity documentation.
